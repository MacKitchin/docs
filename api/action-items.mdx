---

The Action Items API lets you create and manage follow-up tasks that arise from your meetings. You can assign action items to specific users, set due dates and priorities, update status as work progresses, and retrieve all open items across your organization — making it easy to integrate ConnectMeetings task data into your own project management tools and reporting workflows.

---

## GET /meetings/\{meeting_id\}/action-items

List all action items associated with a specific meeting. Use the query parameters to filter by status or narrow results to a single assignee.

<ParamField path="meeting_id" type="string" required>
  The unique identifier of the meeting whose action items you want to list.
</ParamField>

<ParamField query="status" type="string">
  Filter by action item status. Accepted values: `open`, `in_progress`, `complete`, `cancelled`.
</ParamField>

<ParamField query="assignee_id" type="string">
  Filter by the user ID of the assigned owner. Use `GET /users` to look up user IDs.
</ParamField>

```bash
curl -X GET "https://api.connectmeetings.ca/v1/meetings/mtg_01hq8zvpxk3rn5bk9d7w2e4f/action-items?status=open" \
  -H "Authorization: Bearer cm_live_xxxx"
```

## POST /meetings/\{meeting_id\}/action-items

Create a new action item and attach it to a specific meeting. All action items are created with an initial status of `open`.

<ParamField path="meeting_id" type="string" required>
  The unique identifier of the meeting to attach this action item to.
</ParamField>

<ParamField body="title" type="string" required>
  A short, clear description of the task to be completed.
</ParamField>

<ParamField body="assignee_id" type="string" required>
  The user ID of the person responsible for completing this action item. Use `GET /users` to look up valid user IDs.
</ParamField>

<ParamField body="description" type="string">
  Additional context, instructions, or acceptance criteria for the task.
</ParamField>

<ParamField body="due_date" type="string">
  The target completion date in ISO 8601 date format (`YYYY-MM-DD`).
</ParamField>

<ParamField body="priority" type="string">
  The priority level of the task. Accepted values: `low`, `medium`, `high`. Defaults to `medium`.
</ParamField>

```bash
curl -X POST https://api.connectmeetings.ca/v1/meetings/mtg_01hq8zvpxk3rn5bk9d7w2e4f/action-items \
  -H "Authorization: Bearer cm_live_xxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Prepare revised budget projection for Q3",
    "description": "Include variance analysis and updated capital expenditure estimates.",
    "assignee_id": "usr_77gh8ijk9lmn0opq1rst2uvw",
    "due_date": "2024-04-29",
    "priority": "high"
  }'
```

```json
{
  "data": {
    "id": "act_55pq6rst7uvw8xyz9abc0def",
    "meeting_id": "mtg_01hq8zvpxk3rn5bk9d7w2e4f",
    "title": "Prepare revised budget projection for Q3",
    "description": "Include variance analysis and updated capital expenditure estimates.",
    "status": "open",
    "priority": "high",
    "assignee_id": "usr_77gh8ijk9lmn0opq1rst2uvw",
    "due_date": "2024-04-29",
    "created_at": "2024-04-15T16:12:00Z",
    "updated_at": "2024-04-15T16:12:00Z"
  }
}
```

<ResponseField name="data" type="object">
  The newly created action item. See [GET /meetings/\{meeting_id\}/action-items](#get-meetingsmeeting_idaction-items) for a description of all fields.
</ResponseField>

## GET /action-items

List all action items across your entire organization. This endpoint is useful for building dashboards, generating reports, and surfacing overdue tasks without querying each meeting individually.

<ParamField query="status" type="string">
  Filter by action item status. Accepted values: `open`, `in_progress`, `complete`, `cancelled`.
</ParamField>

<ParamField query="assignee_id" type="string">
  Filter by the user ID of the assigned owner.
</ParamField>

<ParamField query="meeting_id" type="string">
  Filter action items to those belonging to a specific meeting.
</ParamField>

<ParamField query="page" type="integer" default="1">
  The page number to return.
</ParamField>

<ParamField query="per_page" type="integer" default="20">
  The number of action items to return per page. Maximum: `100`.
</ParamField>

```bash
curl -X GET "https://api.connectmeetings.ca/v1/action-items?status=open&assignee_id=usr_77gh8ijk9lmn0opq1rst2uvw&page=1&per_page=20" \
  -H "Authorization: Bearer cm_live_xxxx"
```

## PATCH /action-items/\{id\}

Update one or more fields on an existing action item. You only need to include the fields you want to change. The most common use of this endpoint is updating `status` to reflect progress or mark an item complete.

<ParamField path="id" type="string" required>
  The unique identifier of the action item to update.
</ParamField>

<ParamField body="title" type="string">
  An updated title for the action item.
</ParamField>

<ParamField body="description" type="string">
  Updated supporting notes or instructions.
</ParamField>

<ParamField body="status" type="string">
  An updated status. Accepted values: `open`, `in_progress`, `complete`, `cancelled`.
</ParamField>

<ParamField body="assignee_id" type="string">
  The user ID of a new assignee.
</ParamField>

<ParamField body="due_date" type="string">
  An updated due date in `YYYY-MM-DD` format.
</ParamField>

<ParamField body="priority" type="string">
  An updated priority level: `low`, `medium`, or `high`.
</ParamField>

```bash
curl -X PATCH https://api.connectmeetings.ca/v1/action-items/act_55pq6rst7uvw8xyz9abc0def \
  -H "Authorization: Bearer cm_live_xxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "complete"
  }'
```

```json
{
  "data": {
    "id": "act_55pq6rst7uvw8xyz9abc0def",
    "meeting_id": "mtg_01hq8zvpxk3rn5bk9d7w2e4f",
    "title": "Prepare revised budget projection for Q3",
    "description": "Include variance analysis and updated capital expenditure estimates.",
    "status": "complete",
    "priority": "high",
    "assignee_id": "usr_77gh8ijk9lmn0opq1rst2uvw",
    "due_date": "2024-04-29",
    "created_at": "2024-04-15T16:12:00Z",
    "updated_at": "2024-04-30T09:47:00Z"
  }
}
```

<ResponseField name="data" type="object">
  The full updated action item object reflecting all changes. See [GET /meetings/\{meeting_id\}/action-items](#get-meetingsmeeting_idaction-items) for a description of all fields.
</ResponseField>
