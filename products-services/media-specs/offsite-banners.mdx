- **Programme name on the sheet:** BizBash + Connect Targeted Display Program.
- **Production inbox on the sheet:** `bizbashprod@informa.com`.
</Info>

The programme places banners on sites the BizBash and Connect audience uses **beyond BizBash.com**. Existing BizBash or Connect banner creative may be reused.

<Warning>
  This sheet does **not** accept most third-party script-based tags, Flash, or link shorteners. That conflicts with the onsite banner sheets, which do accept many third-party tags. Use this sheet only for offsite / retargeting.
</Warning>

## Units

[Original PDF](/files/media-specs/offsite-banner-retargeting.pdf)

Annual Banner Program sales: submit **at least three of each** unit in the table. Not every unit is required, but the sheet recommends submitting as many as possible. Update creative at least every 90 days on long campaigns, otherwise monthly.

| Ad unit | Dimensions |
| --- | --- |
| Tablet leaderboard | 728 x 90 |
| Mobile leaderboard | Not printed on this sheet |
| Desktop leaderboard | 970 x 90 |
| Half page | 300 x 600 |
| Billboard | 970 x 250 |
| Display box | 300 x 250 |
| Skyscraper | 160 x 600 |

A click-through link is required. UTM links are supported.

## File limits

| Rule | This sheet |
| --- | --- |
| Formats | Static JPEG or PNG |
| File size | **150KB**. There is no flexibility; anything over 150KB is rejected |
| Border | Clearly defined border or a non-white background |
| Third-party tags | Generally not accepted. Confirm any tag with `bizbashprod@informa.com` before sending |

The sheet states that the environment blocks adult, hate-speech, torrent, disaster, and other sensitive categories, and that whitelist or blacklist targeting can be set campaign by campaign.

## Submission

Email files to `bizbashprod@informa.com`. Materials due **five business days** before campaign start.
