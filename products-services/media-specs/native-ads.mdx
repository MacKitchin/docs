The ad sits adjacent to relevant editorial. The sheet recommends two sets of creative. The ad must still be clearly distinguishable as advertising.

## Specs on this sheet

| Element | Rule |
| --- | --- |
| Image | Static JPEG or GIF |
| File size | Maximum 100KB |
| Aspect ratio | 16:9 |
| Imagery | Keep core messaging centred |
| Headline | Up to 75 characters |
| Click-through | Required; UTM allowed |
| Third-party tags | **Not supported** |

Materials due **five business days** before campaign start. New creative may be submitted at any time; the five-day clock still applies. For long campaigns, update about every three months.
