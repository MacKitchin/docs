<Warning>
  The three sheets disagree on maximum file size, whether the desktop leaderboard may animate, and the name of the 300 x 50 mobile unit. Report both versions. Do not average them.
</Warning>

All three sheets require a **click-through link** with every creative. Flash is not accepted. Ads must have a clearly defined border so they are not confused with page content. Materials are due **five business days** before campaign start; rich media and non-standard units need **ten additional days**. Expected time from complete materials to posting is five business days.

## Units on `Onsite Display AdSpecs1.pdf`

[Original PDF](/files/media-specs/onsite-display-adspecs.pdf)

| Ad unit | Dimensions | File types |
| --- | --- | --- |
| Tablet leaderboard | 728 x 90 | JPG, GIF, animation accepted |
| Mobile leaderboard | 300 x 50 | JPG, GIF, static only |
| Desktop leaderboard | 970 x 90 | JPG, GIF, animation accepted |
| Half page | 300 x 600 | JPG, GIF, animation accepted |
| Billboard | 970 x 250 | JPG, GIF, animation accepted |
| Display box | 300 x 250 | JPG, GIF, animation accepted |

Individual/CPM sales: follow the unit purchased; multiple files for the same unit are allowed. A Leaderboard campaign on this sheet requires **all three leaderboard units**. Annual Banner Program: submit **at least one of each** unit in the table. Campaigns are optimised to the most successful unit.

**File limits on this sheet:** JPEG, GIF, or animated GIF; **maximum 100KB**; animation maximum 15 seconds, repeat 3 times. HTML5 is accepted as a zip of all supporting files; compressed size **must not exceed 250KB**. Third-party tags such as DoubleClick are accepted after confirmation. 1x1 impression pixels and UTM click tracking may be supplied instead of third-party tags.

## Units on `Onsite_Display_Ads` (Rev 20220902)

[Original PDF](/files/media-specs/onsite-display-ads-rev-20220902.pdf)

| Ad unit | Dimensions | File types |
| --- | --- | --- |
| Tablet leaderboard | 728 x 90 | JPG, GIF, animation accepted |
| Desktop leaderboard | 970 x 90 | JPG, GIF, **static only** |
| Medium rectangle | 300 x 250 | JPG, GIF, animation accepted |
| Half page | 300 x 600 | JPG, GIF, animation accepted |
| Billboard | 970 x 250 | JPG, GIF, animation accepted |
| Mobile billboard | 300 x 50 | JPG, GIF, static only |

This sheet names the 300 x 250 unit **Medium rectangle** and the 300 x 50 unit **Mobile billboard**. Banner Program and Display Roadblock both ask for one of each unit in the table. Multiple creatives per position, with separate tracking links, are allowed.

**File limits on this sheet:** JPEG, static or animated GIF, and HTML5; **maximum 250KB**; animation maximum 15 seconds, repeat 3 times, maximum 24 fps. Google Ad Manager will reject any ad over 1MB. Third-party tags and impression tags are accepted after confirmation with `production@bizbash.com`.

## Units on `Banner_Program_Specs`

[Original PDF](/files/media-specs/banner-program-specs.pdf)

Same unit table as `Onsite Display AdSpecs1.pdf` (tablet 728 x 90, mobile 300 x 50, desktop 970 x 90, half page 300 x 600, billboard 970 x 250, display box 300 x 250). Desktop leaderboard **animation accepted**. Annual Banner Program: at least one of each unit. Individual/CPM: follow the purchased unit; **mobile versions of the leaderboard and billboard are required**.

**File limits on this sheet:** JPEG, GIF, or animated GIF; **maximum 100KB**; animation maximum 15 seconds, repeat 3 times. Third-party tags such as DoubleClick accepted after confirmation. Custom HTML must be vetted; allow 14 extra days. Third-party and custom HTML tags are **not** accepted for interstitial programmes.

## Shared submission rules

- Send complete, final materials. Incomplete files restart the five-day clock.
- For long campaigns, the sheets recommend new creative about every three months.
- Freelance design support may be available at an hourly rate if the supplier cannot meet spec.
- Topic and category sponsorships are generated from Premium Listing content on the Banner Program sheet; listing specs are separate and are not in this folder.
