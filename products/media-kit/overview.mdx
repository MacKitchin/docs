# Events | Travel | Sports — 2025 media kit

BizBash, TradeShow News Network (TSNN), and Corporate Event News operate as a combined media network for the meetings, events, and trade show industry — positioned as a direct line to decision-makers shaping event experiences.

| Metric | Value |

| Monthly views (owned channels) | **411K** |
| Combined social audience | **378K** |

| Average event budget (audience) | **\$1.1M** |

- Brands selling to **event planners, producers, and trade show professionals**
