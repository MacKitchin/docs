Everyday business terms live on the [Glossary](/reference/glossary). This page is the field-level companion for anyone querying `connect-prod`.

## Everyday word → object

| They say | They mean |
| --- | --- |
| Customer, client | `Account` |
| Deal, opportunity, IO | `Opportunity` (plus `OpportunityLineItem`) |
| Hosted buyer registration | `Registration__c` |
| Event / marketplace | `Marketplace__c` (and `Registration__c.Meeting_Event__c`) |
| Prospect | The object labelled Prospect in the org |

Supplier accounts: `Primary_Category__c LIKE 'Supplier-%'`.

## Business terms with API names

| Term | Field or object |
| --- | --- |
| Marketplace | Also the Salesforce object `Marketplace__c` |
| Hosted buyer | Tracked on `Registration__c.Hosted_Buyer_Type__c` |
| IO / Insertion Order | Every Opportunity carries `IO_Number__c` |
| Product year | `OpportunityLineItem.Product_Year__c` |
| Closed Won | `StageName = 'Closed Won'`, `IsWon = true` |
| Barter | `Barter__c = true`. Always exclude from cash revenue |
| PSL | `Contains_PSL__c` on Opportunity |
| Sales territory | Derived from `BillingState`, not a territory object |
| Expo | Visit event instance. ID on `Marketplace__c.Visit_Expo_Id__c` |
| Visitor | Hosted buyers and most pass holders become `Registration__c`; Connect suppliers become `Supplier_Registration__c` |

## Systems

| Term | Definition |
| --- | --- |
| **`connect-prod`** | The production Salesforce org, ID `00D30000001H2naEAC`. |
| **AdBook (AB2)** | Ad order management. All `AB2__` prefixed fields come from it. Check `AB2__Order_Created__c` before relying on them. |
| **Visit Create** | Event-registration platform (Create API v2). See [Visit Create](/operations/systems/visit-create). |
| **Agentforce** | Salesforce agent platform. Roster runs in `connect-prod`. |
| **Elysia** | Informa's managed AI platform. Not Agentforce. See [Elysia](/operations/ai/elysia). |
| **Elysia Code** | CLI that points Claude Code at the Informa AI gateway. Current version 0.3.0. |

Metric definitions and SOQL live on [Metrics](/operations/data/metrics). Object relationships live on the [data model](/operations/data/data-model).
