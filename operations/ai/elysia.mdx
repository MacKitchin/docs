Elysia is **Informa's managed AI platform**. It sits between our tools and LLM providers. It routes models, keeps traffic on Informa infrastructure, and applies governance, tracing, and billing. Connect uses it in two ways: as an **HTTP API** for chat, agents, and content, and as **Elysia Code**, a CLI that points Claude Code at the Informa AI gateway.

This is **not** Agentforce. Agentforce agents run in `connect-prod`. Elysia is the Informa-wide AI estate. They can meet: Elysia chat can call local MCP tools (Salesforce, Visit Create, Power BI) through the console bridge.

## Two API products

The **Elysia API Guidebook** (Company OS, status Done) distinguishes:

| | Community API | Professional API |
| --- | --- | --- |
| For | Internal use cases and developer testing (performance, pen-test, UAT) | Customer-facing solutions after the checklist |
| Hosting | Informa infrastructure only | Same, after review |
| SLA / security | Not guaranteed for customer-facing use | Requires SLAs, GDPR, AI Governance, cost code, security review, usage metrics |
| Monthly cap (guidebook) | 5,000 calls per instance | After re-engagement with the Elysia product team |
| Support | Integration is not supported by the Elysia product team | Via the product team |
| Contact | `elysia@informa.com` | Professional access form (product team) |

## Auth (two layers)

From the console handoff and the `elysia-api` skill. Do not treat Cloudflare Access as the API bearer token.

1. **OAuth2 client credentials** → Cognito JWT. Token URL used locally: `https://idp.dev.ai.informa.com/oauth2/token`. Send as `Authorization: Bearer …`.
2. **Cloudflare Access / basic auth** protects the docs and some console flows (`CF_Authorization` cookie). It is not the Elysia JWT.

An **app ID** is required on chat and several other calls (`ELYSIA_APP_ID`). Get it from the platform team or the credentials file — not from this page.

## What not to do

- Do not paste keys, client secrets, workspace IDs, config IDs, user IDs, or JWTs into MDX.
- Do not treat Community API as approved for a customer-facing Connect product.
- Do not switch the console off `/v1/ai/chat/stream/completion` without a new live check. The console handoff says `/v2/ai/chat/completion` was unavailable on stage.
- Do not confuse Elysia with Agentforce or with the Bun/TypeScript framework also named Elysia.
