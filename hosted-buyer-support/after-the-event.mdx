## Deposit return

The current guidance says the hosted buyer's \$200 deposit is returned after the assigned appointment schedule has been completed.

<Info>
  Attendance is tracked at each appointment via the check-in process. If a supplier no-showed, the concierge desk logs it so it does not count against the hosted buyer.
</Info>

## Supplier follow-up

Suppliers will typically reach out to the hosted buyer within a few days of the event with tailored proposals based on the hosted buyer's appointment conversation. To keep sourcing moving:

- **Reply to suppliers being progressed** so they know where to focus
- **Politely decline suppliers that are not a fit** so both sides can move on
- **Route serious proposals** into the hosted buyer's normal sourcing workflow
- **Save appointment notes** in the hosted buyer's normal sourcing system for future destination or venue searches

## Post-event feedback

Connect sends a **post-event survey**. Complete it. Feedback directly shapes:

- Which suppliers appear at future events
- Track composition and qualification bars
- Matching rules for next season's appointments
- Programme design and hosted amenities

## Applying for the next event

<Steps>
  <Step title="Check the season calendar">
    See the full [Event calendar](/events/overview) to pick the hosted buyer's next Connect event based on geography, track, and sourcing timing.
  </Step>
  <Step title="Apply early">
    Hosted buyer capacity is capped per track. Applying early improves the hosted buyer's odds of a slot in the hosted buyer's first-choice event.
  </Step>
  <Step title="Update the hosted buyer's profile">
    Refresh the hosted buyer's event portfolio, sourcing volume, and role so the Hosted Buyer Experience Team can vet the hosted buyer against current criteria.
  </Step>
  <Step title="Signal continuity">
    Returning hosted buyers with a strong attendance record are prioritised. The hosted buyer's track record from this event carries into the next application.
  </Step>
</Steps>

## What returning attendance looks like

- Faster application review since the hosted buyer's history is on file
- Priority consideration for oversubscribed tracks
- Continued relationship with the hosted buyer's Hosted Buyer Experience contact where possible
- Eligibility for programmes like Club Connect where they apply
