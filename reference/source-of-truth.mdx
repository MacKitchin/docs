The Source of Truth Registry is the decision layer for information ownership. Check it before editing a page, and before answering when sources disagree.

## Truth levels

<CardGroup cols={3}>
  <Card title="Canonical" icon="badge-check">
    Authoritative. Exactly one canonical entry exists per information type.
  </Card>

  <Card title="Working" icon="flask-conical">
    Useful but unverified. Must be checked before it is relied on, and disclosed as unverified when cited.
  </Card>

  <Card title="Deprecated" icon="archive">
    Retained for history. Must not be used for new work.
  </Card>
</CardGroup>

## Registry rules

1. Every major information type gets exactly **one** Canonical entry.
2. Every entry needs an **Owner** and a **Refresh Cadence**.
3. When a source is replaced, mark the old row **Deprecated** and link the replacement.
4. AI agents should prefer Canonical rows and disclose uncertainty when a row is Working or Deprecated.

## How this site relates to the registry

This Company Brain is a **derived mirror**, not a registry entry in its own right. It restates canonical material in a form that is easier to read and easier for an agent to retrieve from. It does not hold record data and it is not authoritative over a source system.

<Warning>
  If this site and a canonical source disagree, the canonical source wins and this site is out of date. Report the drift to the owner listed above rather than editing around it.
</Warning>
