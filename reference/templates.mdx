## Code Snippets

### SOQL Query Template

```sql
SELECT Id, Name, Account.Name, StageName, Amount
FROM Opportunity
WHERE RecordType.Name = 'Exhibitor Opportunity'
  AND StageName IN ('Closed Won', 'Contract Signed')
  AND CloseDate = THIS_YEAR
ORDER BY Amount DESC
```
